# کیف پول هوشمند (iOS Wallet)

نرم‌افزار حسابداری و کیف پول شخصی تحت وب، بهینه‌شده برای آیفون، با تقویم شمسی و تم آبی روشن.

**سازگار با MySQL / MariaDB (دایرکت‌ادمین و سی‌پنل) و همچنین PostgreSQL (Supabase / Neon / VPS).**

---

## ⚠️ مهم‌ترین نکته قبل از شروع

این برنامه یک اپلیکیشن **Node.js** است، نه سایت PHP. بنابراین:

| شرط | وضعیت |
|-----|-------|
| هاست دایرکت‌ادمین دارای بخش **«Setup Node.js App»** | ✅ کار می‌کند |
| هاست دایرکت‌ادمین **بدون** پشتیبانی Node.js | ❌ کار نمی‌کند (باید VPS بگیرید) |

### چطور بفهمم هاستم Node.js دارد؟

وارد پنل دایرکت‌ادمین شوید و در قسمت جستجوی منو عبارت **Node** را تایپ کنید.
اگر گزینه‌ای با نام **Setup Node.js App** یا **Node.js Selector** دیدید، هاست شما پشتیبانی می‌کند.

اگر نبود، از پشتیبانی هاست بپرسید: «آیا امکان فعال‌سازی Node.js Selector روی اکانت من هست؟»

## 🚀 نصب روی هاست دایرکت‌ادمین (گام به گام)

### گام ۱ — ساخت ساب‌دامنه

1. در دایرکت‌ادمین وارد **Domain Setup → Subdomain Management** شوید.
2. ساب‌دامنه مورد نظر را بسازید، مثلاً: `wallet.example.com`
3. مسیر پوشه آن معمولاً چنین خواهد بود:
   `/home/USERNAME/domains/example.com/public_html/wallet`

### گام ۲ — ساخت دیتابیس MySQL

1. وارد بخش **MySQL Management** شوید.
2. روی **Create new Database** بزنید و موارد زیر را وارد کنید:
   - نام دیتابیس: `wallet_db`
   - نام کاربر: `wallet_user`
   - رمز عبور: یک رمز قوی
3. نام نهایی معمولاً با پیشوند نام اکانت ساخته می‌شود، مثلاً:
   `myuser_wallet_db` و `myuser_wallet_user`

> 📝 این سه مقدار (نام دیتابیس، نام کاربر، رمز) را یادداشت کنید.

### گام ۳ — آپلود فایل‌های پروژه

از طریق **File Manager** یا FTP، تمام فایل‌های پروژه را در پوشه ساب‌دامنه آپلود کنید.

**نباید آپلود شوند:**
- پوشه `node_modules`
- پوشه `.next`
- فایل `.env`

> 💡 ساده‌ترین راه: پروژه را ZIP کنید (بدون سه مورد بالا)، آپلود و در همان پوشه Extract کنید.

### گام ۴ — ساخت اپلیکیشن Node.js

وارد **Setup Node.js App** شوید و روی **Create Application** بزنید:

| فیلد | مقدار |
|------|-------|
| Node.js version | ۲۰ یا بالاتر (بالاترین موجود) |
| Application mode | `Production` |
| Application root | `domains/example.com/public_html/wallet` |
| Application URL | ساب‌دامنه شما |
| Application startup file | `server.js` |

روی **Create** بزنید.

### گام ۵ — تعریف متغیر محیطی دیتابیس

در همان صفحه اپلیکیشن، بخش **Environment variables** را باز کنید و اضافه کنید:

- **Name:** `DATABASE_URL`
- **Value:**
  ```
  mysql://myuser_wallet_user:رمز_عبور@localhost:3306/myuser_wallet_db
  ```

> ⚠️ اگر رمز عبور شما شامل کاراکترهای خاص مثل `@` یا `#` است، باید آن‌ها را encode کنید
> (مثلاً `@` تبدیل به `%40` می‌شود).

### گام ۶ — نصب وابستگی‌ها و بیلد

در صفحه اپلیکیشن، روی دکمه **Run NPM Install** بزنید.

سپس برای بیلد، ترمینال را باز کنید (دکمه **Terminal** در همان صفحه یا از طریق SSH) و اجرا کنید:

```bash
# ورود به محیط مجازی Node (دستور دقیق در صفحه اپلیکیشن نمایش داده می‌شود)
source /home/USERNAME/nodevenv/domains/example.com/public_html/wallet/20/bin/activate
cd /home/USERNAME/domains/example.com/public_html/wallet

npm install
npm run build
```

### گام ۷ — راه‌اندازی مجدد

به صفحه **Setup Node.js App** برگردید و روی **Restart** بزنید.

### گام ۸ — تست نهایی

آدرس زیر را در مرورگر باز کنید:

```
https://wallet.example.com/api/health
```

پاسخ صحیح:

```json
{
  "ok": true,
  "database": "connected",
  "dialect": "mysql",
  "tablesReady": true,
  "hint": "سیستم آماده استفاده است."
}
```

🎉 **جداول دیتابیس به صورت خودکار در همان اولین اجرا ساخته می‌شوند** — نیازی به اجرای هیچ دستور اضافه‌ای نیست.

## ⚡️ جلوگیری از افت سرعت با گذشت زمان

نگرانی شما درست است. با رشد تعداد تراکنش‌ها، اگر برنامه بد طراحی شده باشد کند می‌شود.
موارد زیر در همین نسخه پیاده‌سازی شده‌اند:

### ۱. ایندکس‌گذاری خودکار دیتابیس
هنگام اولین اجرا، این ایندکس‌ها ساخته می‌شوند:

| جدول | ستون‌های ایندکس‌شده |
|------|---------------------|
| `transactions` | `shamsi_date`, `date`, `from_account_id`, `to_account_id`, `type` |
| `accounts` | `type`, `parent_id`, `is_favorite` |

نتیجه: جستجو و گزارش‌گیری حتی با **صدها هزار تراکنش** سریع باقی می‌ماند.

### ۲. صفحه‌بندی سمت سرور
لیست تراکنش‌ها هر بار فقط **۳۰ رکورد** می‌گیرد و با دکمه «نمایش بیشتر» ادامه می‌دهد.
صفحه اصلی فقط **۱۰ تراکنش اخیر** را می‌خواند.

### ۳. محاسبات تجمیعی داخل دیتابیس
مانده حساب‌ها و گزارش سرفصل‌ها با دستورات `SUM` و `GROUP BY` مستقیماً در دیتابیس محاسبه می‌شوند،
نه با خواندن همه رکوردها در حافظه سرور.

### ۴. جستجوی سمت سرور
جستجو با `LIKE` روی ستون‌های ایندکس‌شده انجام می‌شود و نتیجه محدود می‌گردد.

## 💾 پشتیبان‌گیری

### الف) از داخل خود برنامه
مسیر: **تنظیمات ← پشتیبان‌گیری و بازگردانی**

| فرمت | کاربرد |
|------|--------|
| **JSON** | بازگردانی از داخل خود برنامه (دکمه Restore) |
| **SQL** | اجرای مستقیم در phpMyAdmin هاست |

### ب) از پنل دایرکت‌ادمین (توصیه‌شده)
1. وارد **phpMyAdmin** شوید.
2. دیتابیس `wallet_db` را انتخاب کنید.
3. تب **Export** → گزینه **Quick** → فرمت **SQL** → دکمه **Go**.

### ج) پشتیبان‌گیری خودکار با Cron
در بخش **Cron Jobs** دایرکت‌ادمین یک زمان‌بندی روزانه بسازید:

```bash
mysqldump -u myuser_wallet_user -p'رمز_عبور' myuser_wallet_db > /home/USERNAME/backups/wallet_$(date +\%F).sql
```

## 🔄 به‌روزرسانی برنامه در آینده

1. فایل‌های جدید را آپلود کنید (به جز `node_modules`، `.next` و `.env`).
2. در ترمینال اجرا کنید:
   ```bash
   npm install
   npm run build
   ```
3. در **Setup Node.js App** روی **Restart** بزنید.

> داده‌های شما در دیتابیس باقی می‌مانند و ستون‌های جدید به صورت خودکار اضافه می‌شوند.

## 📱 نصب روی آیفون به صورت اپلیکیشن

1. ساب‌دامنه را در **Safari** باز کنید (حتماً Safari، نه Chrome).
2. دکمه **Share** (مربع با فلش رو به بالا) را لمس کنید.
3. **Add to Home Screen** را انتخاب نمایید.

> برای این کار حتماً باید **SSL (HTTPS)** فعال باشد. در دایرکت‌ادمین از بخش
> **SSL Certificates** گواهی رایگان **Let's Encrypt** را برای ساب‌دامنه فعال کنید.

## 🛠 عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| صفحه سفید یا خطای ۵۰۳ | در Setup Node.js App روی Restart بزنید و لاگ‌ها را ببینید |
| `"ok": false` در health | مقدار `DATABASE_URL` را بررسی کنید (نام کاربر و دیتابیس باید با پیشوند اکانت باشد) |
| `tablesReady: false` | کاربر دیتابیس دسترسی `CREATE TABLE` ندارد؛ در MySQL Management دسترسی کامل بدهید |
| خطای `Access denied` | رمز اشتباه است یا کاراکتر خاص encode نشده |
| بعد از آپلود تغییری ندیدم | `npm run build` را دوباره اجرا و اپلیکیشن را Restart کنید |
| Add to Home Screen نیست | SSL فعال نیست یا از Safari استفاده نکرده‌اید |

## 🖥 نصب روی VPS (برای حجم داده بالا)

اگر بعداً به VPS مهاجرت کردید، برنامه بدون تغییر کد با PostgreSQL هم کار می‌کند؛
فقط کافی است `DATABASE_URL` را تغییر دهید:

```
DATABASE_URL=postgresql://user:password@127.0.0.1:5432/wallet_db
```

اجرای دائمی با PM2:

```bash
npm install -g pm2
pm2 start server.js --name wallet
pm2 startup && pm2 save
```
